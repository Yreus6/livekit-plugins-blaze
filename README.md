# Blaze plugin for LiveKit Agents

Support for voice synthesis with [Blaze](https://blaze.vn/).

See [https://blaze.vn/api/documentation/introduction](https://blaze.vn/api/documentation/introduction) for more information.

## Installation

```bash
pip install livekit-plugins-blaze
```

## Pre-requisites

You'll need an API key from Blaze. It can be set as an environment variable: `BLAZE_API_KEY`
